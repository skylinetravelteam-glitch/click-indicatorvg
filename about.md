# Click Indicator

A handcam replacement: shows an image of your choice while you're **not** clicking, and a different one while you **are** clicking or holding. It is drawn inside the game itself, so it works in **fullscreen** and shows up in **OBS / game capture** with no extra overlay.

## Features

- Use **your own images**: pick them from the mod's settings (PNG recommended, transparent edges are cropped automatically so the picture sits right in the corner).
- Choose the **corner**, **size**, **margins** and **opacity**. Changes apply instantly, even from the pause menu.
- Works with **macros and replay bots** (such as XDBot): it follows the game's own button input, so whatever clicks, the indicator follows.
- Handles **2-player / dual** levels (track both players or just one) and optionally counts **platformer** left/right.
- Optional "pop" size for the clicking image, horizontal flip, and "only show while clicking".

No new menus, buttons or screens. Everything is in the normal mod settings.

## Getting started

Install it and play a level. A built-in mouse icon appears in the bottom-right corner. To use your own pictures, open the mod's settings and set **Idle image** and **Clicking image**.

> Tip: if your picture is off the edge, nudge **Horizontal / Vertical margin**. Negative values push it further out.
